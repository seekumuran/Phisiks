# Example projects

Two engineering projects built **on** PHISIKS, kept apart from the engine and the editor. Each one is its own application. It links the engine (`PhisiksCore`), the editor library (`PhisiksEditor`) and the shared kit below, and registers its own scenes. None of them is part of the `Phisiks` editor executable.

| Project | Executable | What it is |
|---|---|---|
| [ProjectMarina](ProjectMarina/README.md) | `ProjectMarina` | a waste-heat membrane-distillation desalination prototype: an editable assembly with schematic flow direction (no thermal or fluid simulation) |
| [OldMcDonald](OldMcDonald/README.md) | `OldMcDonald` | a greenhouse with a mapping drone and a soil rover. Mission playback: A* route and arm IK computed by the engine, flight / mapping / measurements scripted. Plus standalone rover and drone CAD workspaces |

## Layout

| Path | What it is |
|---|---|
| `common/` | `PhisiksProjectKit`: parts, tube / wire runs, subsystem visibility and scene-file buttons (`ProjectKit`), and the CAD workspace framework (`CadWorkspace`) |
| `ProjectMarina/src`, `OldMcDonald/src` | each project's scenes and its `Main.cpp` |
| `ProjectMarina/scenes`, `OldMcDonald/scenes` | the scene files (`phisiks-scene` JSON) the applications save and reopen |
| `assets/meshes/` | the projects' meshes (CC0, generated by `projectassetgen` from `tools/`) |
| `tools/` | `projectassetgen`: regenerates `assets/` from the projects' spec headers |

## Building

The projects are built by default with the rest of the repository (`PHISIKS_BUILD_PROJECTS=ON`). Configure with `-DPHISIKS_BUILD_PROJECTS=OFF` to build only the engine, the editor and the examples; this also skips the runtime tests, which host the projects.

## Opening the scene files in the PHISIKS editor

The scene files are ordinary `phisiks-scene` JSON, so `Phisiks --assets projects/assets --open projects/OldMcDonald/scenes/rover_cad.scene.json` opens the geometry in the plain editor. The project behaviour (mission playback, exploded views, workspace panels) lives in the projects' own executables.

## Regenerating the meshes

```sh
Build/bin/Release/projectassetgen projects/assets     # deterministic: the output equals the committed files
```
