# Clean-room ledger (final, P6)

**Status: every source file in the repository is original Phisiks code, released under the MIT licence (`LICENSE`).** Third-party libraries are used unmodified from `vendor/` under their own licences (`THIRD_PARTY_NOTICES.md`). Sample assets are generated by `tools/assetgen` and released under CC0 (`assets/LICENSE.md`).

## How Phisiks was written
Phisiks began as a refactor of an existing, unlicensed game code base. Phases P0–P5 replaced it module by module, under three rules:
- **Contract only.** The old code was read only to learn the interface contract (names, parameters, observable behaviour) that not-yet-replaced code still called. Implementations were written from scratch against public documentation (OpenGL, GLFW, PhysX, Windows Core Audio, the C++ standard library) and verified by new tests.
- **Shims, then deletion.** Where old callers still existed, the old files became thin forwarding shims to the new code. P6 deleted all of them.
- **No borrowed data.** No assets, shaders or data files were carried over. Shaders were written new (P4); assets are generated (P5).

## Verification at P6 (tag `p6-clean-engine`)
1. **Nothing of the original code base remains in the working tree.**
   - The inherited sources (`src/`) and data (`res/`) were removed. Their tracked parts stay recoverable from tag `pre-strip`; the untracked parts were moved out of the repository.
   - The build compiles only `engine/`, `apps/`, `tests/`, `tools/` and two vendor translation units: the glad GL loader and the stb image implementation.
2. **Strict name check.** `tools/check_layering.cmake` runs before every build and fails it if any project text file names the original code base, its game, or its namespaces/directories.
3. **Strict layering.** The same script checks includes:
   - public headers include only the public API (`Phisiks/...`), glm, EnTT and the standard library;
   - apps and runtime tests include only the public API, glm, EnTT, the standard library and their own local headers;
   - unit tests use no backend headers.
4. **Behaviour is covered by tests written for Phisiks:** 100 headless unit tests, 83 runtime checks, and deterministic-replay and layering ctests.
